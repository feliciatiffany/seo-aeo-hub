# SEO & AEO Hub

A self-hosted dashboard that pulls **Ahrefs**, **Google Analytics 4** and **Google Search Console** into one page for a marketing team. It shows how a site is found in Google and in AI assistants such as ChatGPT and Perplexity (AEO, answer engine optimisation), what visitors do once they arrive, and what to work on next.

**Live demo:** https://feliciatiffany.github.io/seo-aeo-hub/

The demo uses a made-up company (Northwind Analytics, `northwind.example`). Every number, post and link in it is invented and generated by [`demo/make_demo.py`](demo/make_demo.py). No real company data and no API keys are in this repository.

## What it does

- **Growth:** the last 28 days against the 28 before for visitors, demo clicks, sign-ups, Google clicks and impressions, and AI-assistant visits, plus weekly trend charts.
- **Strategies:** prioritised SEO, AEO, conversion and tracking actions generated from that week's numbers. Each one fires only when the data supports it, for example searches sitting just below page one, pages people see in Google but skip, or links that were lost.
- **Traffic & changes:** daily traffic with every site change marked on the day it went live (new posts, post edits and other site changes from the website's git history), plus a before/after table to see what may have moved the numbers.
- **Visitors & actions:** visitors, engaged visits, Book demo / Sign up / Log in clicks, the visit-to-action steps, and which sources bring the people who convert.
- **Search Console, Traffic & AI referrals:** quick-win searches, top pages, and visits from each AI assistant.
- **Blog & release notes:** every post, read from the site's Markdown, with views, Google clicks, position, AI visits and demo clicks, and a daily chart per post.
- **Authority & keywords (Ahrefs):** Domain Rating, referring domains (new and lost), top pages and keywords.
- **Time ranges:** one "Charts show" dropdown for the whole page (last month, 3, 6 or 12 months, all time), and a dropdown on every chart.
- **Search and Ask AI:** a search bar that jumps to any section, number or table row; and an assistant panel that answers questions about the page's numbers when the page is published as a claude.ai artifact.
- **Light and dark themes**, and a layout that works on phones.

## Built to spend as little API budget as possible

| Source | Cost | How the hub keeps it low |
|---|---|---|
| Ahrefs | API units (paid) | Monthly and per-run budgets checked before and during every run; a minimum gap between live runs; the costliest list (referring domains) is re-pulled only every couple of weeks and reused in between; units logged per call |
| Google Analytics 4 | Free token quota | Day-by-day reports are stored locally and each run fetches only new days (plus the last 3, which Google can still revise); token use per run is capped |
| Search Console | Free request quota | Same incremental history (16 months backfilled once); a capped number of requests per run |

## How it works

```
fetch_ahrefs.py   ─┐
fetch_google.py   ─┼─▶ data/ (raw JSON + daily history) ─▶ build_dashboard.py ─▶ one self-contained HTML page
website Markdown  ─┤                                          (dashboard_template.html)
website git log   ─┘
```

- **Python standard library** for the Ahrefs client and the build; `google-auth` for read-only Google sign-in (OAuth or service-account impersonation, no key files needed).
- **One HTML file** with inline CSS and vanilla JavaScript and no front-end framework. Charts are hand-drawn SVG, and all data is embedded in the page, so it can be hosted anywhere.
- **`update.sh`** runs the whole refresh; schedule it weekly with cron or launchd.

## Run the demo locally

```bash
python3 demo/make_demo.py
python3 -m http.server 8000 --directory docs
```

Then open http://localhost:8000.

## Use it with your own site

```bash
cp .env.example .env              # add your Ahrefs key, GA4 property, Search Console site, brand and site URL
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python fetch_google.py --login   # one-time read-only Google sign-in
python3 fetch_ahrefs.py           # free test run against Ahrefs' sample site
python3 fetch_ahrefs.py --live    # your domain (uses API units)
.venv/bin/python fetch_google.py
python3 build_dashboard.py        # writes dashboard.html and public/index.html
```

All settings, budgets and guards are listed in [`.env.example`](.env.example). `.env`, `secrets/` and `data/` are git-ignored.
